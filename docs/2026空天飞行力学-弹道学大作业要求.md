# 2026 空天飞行力学 — 弹道学大作业要求

## DF-X 弹道导弹最大射程弹道设计

DF-X 号是一款陆基单级液体燃料弹道导弹，本课程设计以该导弹为对象，在所给假设条件下，要求设计其最大射程飞行弹道，分析不同参数对导弹射程的影响规律，并给出主要参数的变化曲线。

## 2、问题假设

弹道设计时，主要考虑如下假设：

### 地球引力场及形状模型
精确的地球引力场计算是十分复杂的，本问题中除基本球形引力外，非球形引力仅考虑到 J2 项。假设地球形状为标准椭球。

### 推力模型
发动机推力和比冲均采用标称值。开机后，推力立刻达到额定值；关机后，推力瞬时降为 0。主动段导弹质量根据秒耗量计算得到，关机后导弹质量即为弹头质量。

### 地球大气参数
地球大气模型采用书中所述的标准大气表，气动力仅在 90 km 高度以下时考虑，超过该高度不考虑气动力。再入段不考虑气动力影响。

### 俯仰程序角模型
假设偏航程序角和滚转程序角恒定为 0，仅考虑俯仰程序角的变化。主动段俯仰程序角假设为图 1 所示的函数形式。

导弹垂直起飞，起始程序角 φ_p0 = 90°，经过 t1 时间的固定程序角飞行后进入转弯阶段，该阶段程序角呈线性规律减小，经过 t2 − t1 时间后，再次保持固定程序角飞行，直至达到预定关机时间 tk，发动机进行关机。

（图 1：俯仰程序角示意图）

其中，两段固定程序角飞行时间均设定为 5s，即 t1 = 5s、tk − t2 = 5s。中间线性下降过程可由下式表示：

```
φ_p(t) = K·t + φ_p0
```

由图 1 可知 φ_pf = φ_p(t2)，终端俯仰程序角满足约束 **10° ≤ φ_pf ≤ 70°**，关机时的导弹质量不能小于 **3000 kg**。

给定图 1 所示的俯仰程序角规律后，需要设计的参数主要为：
- **终端俯仰程序角** φ_pf
- **起飞时的燃料装载质量** m_f

通过调节这两个参数可改变导弹的飞行弹道。当这两个参数确定后，导弹的最大射程飞行弹道也是唯一确定的。

## 3、问题要求

本课程设计分为两个难度层次：**Level 1** 和 **Level 2**。

### Level 1

- 考虑地球自转
- **不对** φ_pf 和 m_f 做优化
- 实现给定一组 φ_pf 和 m_f 即可输出一条飞行弹道的功能，输出相应轨迹

#### Level 1 分析重点

| 序号 | 分析重点 | 备注 |
|------|----------|------|
| 1 | 分析地球自转对飞行弹道的影响 | |
| 2 | 分析不同 φ_pf 和 m_f 对飞行弹道的影响 | |
| 3 | 分析不同数值积分方法对弹道积分精度的影响 | |
| 4 | 分析大气密度干扰对飞行弹道的影响 | |

### Level 2

- 考虑地球自转
- 对 φ_pf 和 m_f 做优化
- 给出最大射程解，输出最优轨迹

#### Level 2 分析重点

| 序号 | 分析重点 | 备注 |
|------|----------|------|
| 1 | 分析初始射向对最大射程弹道的影响 | |
| 2 | 分析两种以上优化方法对最优轨迹的影响 | |
| 3 | 分析不同引力场对飞行弹道的影响（如 J2/J4 等） | |
| 4 | 给定目标点，寻找合适的参数（A0、φ_pf 和 m_f）使得导弹可以精确命中目标 | |
