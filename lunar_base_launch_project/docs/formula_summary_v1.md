本文档汇总了升级后的月球基地运载方案建模中使用的全部公式，涵盖从上升段到地月转移的完整物理数学模型。

## 一、数值积分方法

### 1.1 四阶 Runge-Kutta 积分 (RK4)

对于一阶微分方程组 dx/dt = f(t, x)，RK4 单步积分公式为：

```
k1 = f(t_n, x_n)
k2 = f(t_n + Δt/2, x_n + Δt·k1/2)
k3 = f(t_n + Δt/2, x_n + Δt·k2/2)
k4 = f(t_n + Δt, x_n + Δt·k3)

x_{n+1} = x_n + (Δt/6)·(k1 + 2k2 + 2k3 + k4)
```

**局部截断误差**: O(Δt^5)，**全局误差**: O(Δt^4)

### 1.2 Dormand-Prince 5(4) 自适应积分 (RK45)

七级五阶嵌入四阶方法，Butcher 表采用 DOPRI54 系数。步长控制采用 PI 控制器：

```
h_new = h · min(2.0, max(0.5, 0.9 · error^(-0.2)))
```

误差估计采用 5阶和4阶解的差值，通过容差 (atol + rtol·|x|) 标度化。

## 二、标准大气模型 (杨炳蔚教材模型)

### 2.1 位势高度转换

```
H = R_E · h / (R_E + h)
```

其中 H 为位势高度，h 为几何高度，R_E = 6371000 m。

### 2.2 大气分层模型 (0-120 km)

| 层号 | 位势高度范围 | 温度梯度 L (K/km) | 底部温度 T_base (K) |
|------|-------------|-------------------|---------------------|
| 0 (对流层) | 0-11 km | -6.5 | 288.15 |
| 1 (对流层顶) | 11-20 km | 0 (等温) | 216.65 |
| 2 (平流层下) | 20-32 km | +1.0 | 216.65 |
| 3 (平流层上) | 32-47 km | +2.8 | 228.65 |
| 4 (平流层顶) | 47-51 km | 0 (等温) | 270.65 |
| 5 (中间层) | 51-71 km | -2.8 | 270.65 |
| 6 (中间层上) | 71-84.852 km | -2.0 | 214.65 |
| 7 (中间层顶) | 84.852-92 km | 0 (等温) | 186.87 |
| 8 (热层) | 92-120 km | +4.0 | 186.87 |

### 2.3 非等温层 (L ≠ 0) 温度、压强、密度

**温度**:
```
T(H) = T_base + L · (H - H_base)
```

**压强** (由流体静力学方程 dp/dH = -ρ·g₀ 和理想气体状态方程 p = ρ·R·T 导出):
```
p(H) = p_base · [T_base / T(H)]^(g₀/(R·L))
```

**密度** (理想气体状态方程):
```
ρ(H) = p(H) / (R · T(H))
```

其中:
- g₀ = 9.80665 m/s² (标准重力加速度)
- R = 287.05287 J/(kg·K) (干空气气体常数)

### 2.4 等温层 (L = 0)

```
T(H) = T_base

p(H) = p_base · exp[-g₀ · (H - H_base) / (R · T_base)]

ρ(H) = p(H) / (R · T_base)
```

### 2.5 声速与粘性

**声速**:
```
a = √(γ · R · T)
```
其中 γ = 1.4 (空气比热比)

**Sutherland 动力粘性公式**:
```
μ = μ_ref · (T/T_ref)^(3/2) · (T_ref + S) / (T + S)
```
其中 μ_ref = 1.716×10⁻⁵ Pa·s, T_ref = 273.15 K, S = 110.4 K

## 三、地球引力场模型

### 3.1 球形二体引力

```
a_grav = -(μ_E / r³) · r
```

其中 μ_E = 3.986004418×10¹⁴ m³/s² (地球引力参数)

### 3.2 J2 项 (地球扁率，量级 ~10⁻³)

引力势函数:
```
U_J2 = -(μ/r) · J2 · (R_E/r)² · P₂(sin φ)
P₂(x) = (3x² - 1)/2
```

ECEF 笛卡尔加速度分量:
```
a_x = (-3J2·μ·R_E²·x / 2r⁵) · (1 - 5z²/r²)
a_y = (-3J2·μ·R_E²·y / 2r⁵) · (1 - 5z²/r²)
a_z = (-3J2·μ·R_E²·z / 2r⁵) · (3 - 5z²/r²)
```

其中 J2 = 1.08262668×10⁻³

### 3.3 J3 项 (梨形/南北不对称，量级 ~10⁻⁶)

```
U_J3 = (μ/r) · J3 · (R_E/r)³ · P₃(sin φ)
P₃(x) = (5x³ - 3x)/2
```

其中 J3 = -2.53265649×10⁻⁶

### 3.4 J4 项 (下一阶带谐项，量级 ~10⁻⁶)

```
U_J4 = -(μ/r) · J4 · (R_E/r)⁴ · P₄(sin φ)
P₄(x) = (35x⁴ - 30x² + 3)/8
```

其中 J4 = -1.61962159×10⁻⁶

### 3.5 完整引力加速度 (ECI/ECEF)

```
a_total = a_spherical + a_J2 + a_J3 + a_J4
```

## 四、上升段质点动力学方程

### 4.1 状态向量

在 ECI (地心惯性) 坐标系中，状态向量为:

```
x = [r_x, r_y, r_z, v_x, v_y, v_z]^T
```

质量 m 单独进行代数更新。

### 4.2 运动方程 (6-DOF)

```
dr/dt = v

dv/dt = g(r)                          ← 引力 (球形+J2+J3+J4)
       + (T/m) · û_T                   ← 推力加速度
       - (D/m) · (v_rel / |v_rel|)     ← 气动阻力加速度
       - 2·ω_E × v                     ← 科里奥利加速度
```

其中:
- **g(r)** 为完整引力加速度 (§3.5)
- **T** 为发动机推力 (含大气反压修正)
- **û_T** 为推力方向单位矢量
- **D** 为气动阻力
- **ω_E** × **v** 为 Coriolis 项 (ω_E = 7.2921159×10⁻⁵ rad/s)

### 4.3 质量消耗方程

```
dm/dt = -T / (I_sp · g₀)
```

其中 I_sp 为比冲 (s), g₀ = 9.80665 m/s²

### 4.4 推力方向计算

在 ECI 系中，推力方向由发射方位角 A 和程序角 φ(t) 确定:

```
û_up = r / |r|                                    (当地天向)
û_east = (ω_E × r) / |ω_E × r|                     (当地东向)
û_north = û_up × û_east                            (当地北向)

û_horizontal = cos(A)·û_north + sin(A)·û_east      (水平发射方向)

û_T = sin(φ)·û_up + cos(φ)·û_horizontal            (推力方向)
```

### 4.5 程序角模型 (分段光滑俯仰转弯)

```
φ(t) = 90°                                              t ≤ t_v
φ(t) = 90° - [(t-t_v)/(t_end-t_v)]^s · (90° - φ_f)     t_v < t < t_end
φ(t) = φ_f                                              t ≥ t_end
```

设计变量: **t_v** (垂直上升时间), **t_end** (转弯结束时间), **φ_f** (终端程序角), **s** (形状指数)

## 五、气动力模型

### 5.1 相对大气速度

大气随地球固连转动:
```
v_atm = ω_E × r
v_rel = v - v_atm
```

### 5.2 动压

```
q = (1/2) · ρ(h) · |v_rel|²
```

### 5.3 气动阻力

```
D = (1/2) · ρ(h) · |v_rel|² · C_D · S_ref
```

其中 C_D 为阻力系数 (0.28-0.30), S_ref 为参考面积 (78.5 m²)

### 5.4 驻点热流密度 (Sutton-Graves 关联式)

```
q̇_dot = k · √(ρ/R_n) · V³
```

其中 k ≈ 1.83×10⁻⁴ (SI), R_n ≈ 1.0 m (头部曲率半径)

## 六、推力模型 (含大气反压修正)

### 6.1 推力随高度的变化

```
T(h) = T_vac - (T_vac - T_sl) · p(h)/p₀
```

其中 T_vac 为真空推力, T_sl 为海平面推力, p₀ = 101325 Pa

### 6.2 比冲随高度的变化

```
I_sp(h) = I_sp,vac - (I_sp,vac - I_sp,sl) · p(h)/p₀
```

### 6.3 分级模型

第 j 级的推进剂消耗和干质量抛弃:

```
ṁ_j = T_j / (I_sp,j · g₀)           (质量流率)
t_burn,j = m_prop,j / ṁ_j           (燃烧时间)
m⁺ = m⁻ - m_dry,j                  (级间分离质量跃变)
```

## 八、轨道力学模型

### 8.1 活力公式 (Vis-Viva)

```
v² = μ · (2/r - 1/a)
```

其中 a 为半长轴

### 8.2 Hohmann 转移

从半径 r₁ 圆轨道到半径 r₂ 圆轨道:

```
a_transfer = (r₁ + r₂) / 2
v_1 = √(μ/r₁)                        (初始圆轨道速度)
v_t1 = √(μ·(2/r₁ - 1/a_transfer))    (转移椭圆起点速度)
Δv_1 = v_t1 - v_1                    (第一次脉冲)

v_2 = √(μ/r₂)                        (目标圆轨道速度)
v_t2 = √(μ·(2/r₂ - 1/a_transfer))    (转移椭圆终点速度)
Δv_2 = v_2 - v_t2                    (第二次脉冲)

Δv_total = |Δv_1| + |Δv_2|
```

### 8.3 飞行时间

```
TOF = π · √(a³ / μ)
```

## 九、拼接圆锥 TLI 模型 (Patched Conic)

### 9.1 转移椭圆参数

```
r₁ = R_E + h_LEO
r₂ = r_EM = 384,400,000 m
a = (r₁ + r₂) / 2
e = 1 - r₁/a
```

### 9.2 TLI 速度增量

```
v_c = √(μ_E / r₁)                      (LEO 圆轨道速度)
v_p = √(μ_E · (2/r₁ - 1/a))            (近地点速度)
Δv_TLI = v_p - v_c                     (TLI 冲量)
```

### 9.3 双曲线超速 (v_∞)

```
v_∞² = v_p² - 2·μ_E/r₁ = 2·E           (轨道能量)
C₃ = v_∞²                              (发射能量参数，km²/s²)
```

### 9.4 月球影响球 (SOI) 半径

```
r_SOI = r_EM · (μ_Moon / μ_Earth)^(2/5) ≈ 66,200 km
```

### 9.5 月球到达速度

```
v_Moon_orbit = √(μ_E / r_EM)           (月球轨道速度 ≈ 1.02 km/s)
v_apogee = √(μ_E · (2/r_EM - 1/a))     (远地点速度)
v_rel_Moon = |v_apogee - v_Moon_orbit|  (相对月球速度)
v_arrival_SOI = √(v_rel_Moon² + 2·μ_Moon/r_SOI)
```

### 9.6 中途修正 (TCM)

统计模型，总 TCM 预算约 15-30 m/s (3σ):
```
Δv_TCM = Δv_TCM1 + Δv_TCM2 + Δv_TCM3
       ≈ 12 + 8 + 5 = 25 m/s
```

### 9.7 总任务速度增量

```
Δv_total = Δv_TLI + Δv_TCM (+ Δv_LOI 可选)
```

## 十、齐奥尔科夫斯基火箭方程与质量预算

### 10.1 理想火箭方程

```
Δv = I_sp · g₀ · ln(m₀/m_f)
MR = m₀/m_f = exp(Δv / (I_sp · g₀))
```

### 10.2 TLI 质量预算

给定:
- m_cargo = 40 t (总载荷)
- m_adapter = 4 t (对接机构/适配器)
- ε = m_dry / m_prop (结构系数, 通常 0.06-0.10)

```
m_fixed = m_cargo + m_adapter
MR = exp(Δv_TLI / (I_sp · g₀))
m_prop = (MR - 1) · m_fixed / (1 - (MR - 1) · ε)
m_dry = ε · m_prop
m_stack,LEO = m_fixed + m_prop + m_dry
m_LEO,per_launch = m_stack,LEO / 2
```

## 十三、可靠性模型

### 13.1 发动机簇可靠性 (二项分布)

不允许发动机失效:
```
R_cluster = r^N
```

允许最多 f 台失效:
```
R_cluster = Σ(k=0→f) C(N,k) · (1-r)^k · r^(N-k)
```

### 13.2 多发任务可靠性

N 次发射中至少 K 次成功:
```
P(N,K;R) = Σ(s=K→N) C(N,s) · R^s · (1-R)^(N-s)
```

两发全成功: P₂ = R²
三发至少两发: P₃,₂ = 3R² - 2R³

### 13.3 总任务可靠性链

```
R_total = R_launch^N · R_rendezvous · R_TLI
```

## 十四、粒子群优化 (PSO)

### 14.1 速度和位置更新

```
v_i^{(k+1)} = w · v_i^{(k)}
            + c₁ · r₁ · (pbest_i - x_i^{(k)})
            + c₂ · r₂ · (gbest - x_i^{(k)})

x_i^{(k+1)} = x_i^{(k)} + v_i^{(k+1)}
```

### 14.2 惯性权重线性衰减

```
w(k) = w_start - (w_start - w_end) · k / K_max
```

其中 w_start = 0.9, w_end = 0.4

### 14.3 参数设置

- 种群大小: 40-50
- 最大迭代: 80-100
- 认知系数 c₁ = 2.0
- 社会系数 c₂ = 2.0
- 早停容忍: 15-20 代无改善

## 十五、遗传算法 (GA)

### 15.1 选择算子 (锦标赛选择)

从种群中随机选取 k 个个体，取适应度最优者。

### 15.2 交叉算子 (混合交叉 BLX-α)

```
child_j = U(c_min - α·Δ, c_max + α·Δ)
```
其中 Δ = |parent1_j - parent2_j|, α = 0.25

### 15.3 变异算子 (高斯变异)

```
child_j = child_j + N(0, σ²)
σ = mutation_std_fraction · (upper_j - lower_j)
```

### 15.4 精英保留

每代保留最优的 e 个个体直接进入下一代。

## 十七、Lambert 问题 (通用变量法)

### 17.1 问题描述

给定 r₁, r₂, TOF, μ, 求解 v₁, v₂:
```
r(t₀) = r₁,  r(t₀+TOF) = r₂
```

### 17.2 Stumpff 函数

```
C(z) = { (1 - cos(√z))/z              z > 0
       { (cosh(√(-z)) - 1)/(-z)       z < 0
       { 1/2                          z = 0

S(z) = { (√z - sin(√z)) / z^(3/2)     z > 0
       { (sinh(√(-z)) - √(-z)) / (-z)^(3/2)  z < 0
       { 1/6                          z = 0
```

### 17.3 通用变量时间方程

```
√μ · t = χ³ · S(z) + A · √y
z = α · χ²
y = r₁ + r₂ + A · (z·S - 1)/√C
```
